# مدونة أيوب إعزة — دليل النشر المجاني الكامل

هذا الموقع جاهز للنشر مجاناً بالكامل على Netlify، مع لوحة تحكم حقيقية
تتيح لك إضافة وتعديل المقالات وإعدادات الموقع (بما فيها روابط الدعم
المالي) من المتصفح، بدون أي معرفة برمجية بعد الإعداد الأول.

**التكلفة: 0$** — لا حاجة لبطاقة ائتمان في أي خطوة.

---

## الخطوة 1: أنشئ حساب GitHub (إن لم يكن لديك)

1. اذهب إلى https://github.com وأنشئ حساباً مجانياً.
2. أنشئ مستودعاً (Repository) جديداً، مثلاً باسم `ayoub-blog`، واجعله **Public** أو **Private** (كلاهما يعمل).
3. ارفع جميع ملفات هذا المشروع إلى المستودع (يمكنك السحب والإفلات من واجهة GitHub مباشرة عبر زر "Add file → Upload files").

## الخطوة 2: أنشئ حساب Netlify واربطه بـ GitHub

1. اذهب إلى https://app.netlify.com وسجّل حساباً مجانياً (يمكنك التسجيل مباشرة بحساب GitHub).
2. اضغط **"Add new site" → "Import an existing project"**.
3. اختر GitHub، ثم اختر المستودع الذي رفعت إليه الملفات.
4. اترك إعدادات البناء كما هي (لا حاجة لأمر بناء، الموقع ثابت) واضغط **Deploy**.
5. بعد دقائق سيصبح موقعك متاحاً على رابط مجاني مثل: `your-site-name.netlify.app`
   (يمكنك تغيير الاسم من Site settings → Change site name).

## الخطوة 3: فعّل لوحة التحكم (Netlify Identity + Git Gateway)

هذا ما يشغّل صفحة `/admin` الخاصة بك:

1. من لوحة Netlify لموقعك، اذهب إلى **Site configuration → Identity**.
2. اضغط **Enable Identity**.
3. انزل إلى **Registration preferences** واختر **Invite only** (حتى لا يسجل أي شخص آخر).
4. انزل إلى **Services → Git Gateway** واضغط **Enable Git Gateway**.
5. ارجع إلى تبويب **Identity**، واضغط **Invite users**، وأدخل بريدك الإلكتروني (بريد أيوب إعزة).
6. ستصلك رسالة دعوة على بريدك — افتحها واضبط كلمة مرور حسابك.

## الخطوة 4: افتح لوحة التحكم

1. اذهب إلى `https://your-site-name.netlify.app/admin`
2. سجّل الدخول بالبريد وكلمة المرور اللذين ضبطتهما.
3. من هنا يمكنك:
   - **المقالات**: إضافة/تعديل/حذف أي مقال (العنوان، المحتوى، التصنيف، التاريخ...).
   - **إعدادات الموقع**: تغيير عنوان الموقع، نص الصفحة الرئيسية، نص صفحة "حول"،
     وأهم شيء: **روابط الدعم المالي** (PayPal / Ko-fi / Buy Me a Coffee).

كل تعديل تحفظه من لوحة التحكم يُرفع تلقائياً إلى GitHub، وNetlify يعيد نشر
الموقع تلقائياً خلال ثوانٍ.

---

## إضافة روابط الدعم المالي (مجانية الإنشاء)

- **PayPal.me**: أنشئ رابطك المجاني من https://paypal.me
- **Ko-fi**: أنشئ صفحة مجانية من https://ko-fi.com
- **Buy Me a Coffee**: أنشئ صفحة من https://buymeacoffee.com (قد تتطلب ربط حساب بنكي لاستلام الأموال لاحقاً، لكن الإنشاء نفسه مجاني)

بعد إنشاء الروابط، الصقها في حقول الدعم المالي داخل لوحة التحكم
(**إعدادات الموقع**)، واحفظ — ستظهر تلقائياً في صفحة "ادعم المحتوى".

---

## ربط دومين مجاني لاحقاً (اختياري)

- يمكنك إبقاء رابط `your-site-name.netlify.app` مجاناً للأبد.
- إذا رغبت لاحقاً بدومين مخصص مثل `ayoubiazza.com`، ستحتاج لشرائه من مزود
  دومينات (يكلف عادة بين 10-15$ سنوياً)، ثم ربطه من Netlify عبر
  **Domain settings → Add a domain**. هذه الخطوة الوحيدة غير المجانية،
  ويمكن تأجيلها متى ما توفر المال دون أن يؤثر ذلك على عمل الموقع.

## هيكل الملفات

```
├── index.html          الصفحة الرئيسية
├── post.html            قالب عرض المقال
├── about.html            صفحة "حول"
├── support.html          صفحة الدعم المالي
├── styles.css            تنسيق الموقع
├── script.js              منطق عرض المحتوى
├── netlify.toml           إعدادات النشر
├── content/
│   ├── posts.json         بيانات المقالات (تُعدَّل من /admin)
│   └── settings.json      إعدادات الموقع (تُعدَّل من /admin)
├── admin/
│   ├── index.html         صفحة لوحة التحكم
│   └── config.yml         تهيئة لوحة التحكم
└── images/                الصور المرفوعة من لوحة التحكم
```
